# Kaikata

Календарь с будильником для Android: события и задачи из Google Календаря, полноэкранный сигнал, виджеты, быстрая запись голосом.

## Скачать

**[⬇ Последняя версия](https://github.com/dayu8080/kaikata-releases/releases/latest)** — откройте ссылку с телефона и нажмите на файл `Kaikata-….apk` в разделе Assets.

Все версии: [Releases](https://github.com/dayu8080/kaikata-releases/releases).

## Установка

1. Скачайте APK и откройте его из уведомления или из папки «Загрузки».
2. Если телефон спросит, разрешите установку из этого источника (браузера или «Моих файлов»).
3. Нажмите «Установить». Новая версия ставится поверх старой, события и настройки сохраняются.
4. При первом запуске разрешите доступ к календарю и уведомлениям и выберите аккаунт Google.

Нужен Android 10 или новее.
